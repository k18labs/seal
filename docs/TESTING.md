# Testing

Run `cargo test --locked`, `cargo fmt --all -- --check`, and `cargo clippy --all-targets --all-features --locked -- -D warnings`. Unit tests include SHA-256/BLAKE3 vectors, canonical manifests, parser limits, path rules, signature envelope encoding, and terminal escaping. Integration tests cover empty/large file hashing, JSON, encrypted key generation and signing, wrong passphrases, ciphertext tampering, wrong trusted keys, canonical manifest creation/signing, missing/modified/unexpected files, output path checks, and symlink/junction rejection. Unix asserts private-key mode `0600`; Windows inspects the protected DACL.

CI is configured for Linux, macOS, and Windows on x86-64 and ARM64; all six remote jobs passed on the current implementation. A bounded fuzz smoke run passed for all four targets. The six-target clean rebuild comparison and release-candidate build/SBOM workflow passed, and `gh attestation verify` accepted all six archives and the SBOM downloaded from the workflow run. The manual benchmark recorded hash, startup, file and manifest signing/verification, large-file and many-small-file manifest creation, peak RSS, and binary size results in [PERFORMANCE.md](PERFORMANCE.md).

Remaining coverage includes unreadable-path handling, concurrent file replacement/mutation and symlink-swap stress, prompt-confirmation mismatch, and partial-write rollback. Remote CI does not establish an atomic filesystem snapshot; the implementation detects some changes while reading and documents that inputs must remain quiescent.
