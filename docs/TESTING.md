# Testing

Run `cargo test --locked`, `cargo fmt --all -- --check`, and `cargo clippy --all-targets --all-features --locked -- -D warnings`. Unit tests include SHA-256/BLAKE3 vectors, canonical manifests, parser limits, path rules, signature envelope encoding, partial-write rollback, and terminal escaping. Integration tests cover empty/large file hashing, JSON, encrypted key generation and signing, wrong passphrases, confirmation mismatch, ciphertext tampering, wrong trusted keys, canonical manifest creation/signing, missing/modified/unexpected files, output path checks, symlink/junction rejection, concurrent file-to-symlink replacement, and key-file rollback. Shared CLI test helpers cap subprocesses at 60 seconds; the race test caps each attempt at 5 seconds, and the PTY prompt test applies 15-second deadlines. Unix asserts private-key mode `0600`; Windows inspects the protected DACL.

CI is configured for Linux, macOS, and Windows on x86-64 and ARM64. A bounded fuzz smoke run passed for all four targets. The six-target clean rebuild comparison and release-candidate build/SBOM workflow passed, and `gh attestation verify` accepted all six archives and the SBOM downloaded from the workflow run. The manual benchmark recorded hash, startup, file and manifest signing/verification, large-file and many-small-file manifest creation, peak RSS, and binary size results in [PERFORMANCE.md](PERFORMANCE.md).

Unix CI exercises unreadable-file handling; key generation also verifies it removes a newly written private key when creating the public key fails. Remote CI does not establish an atomic filesystem snapshot; the implementation detects some changes while reading and documents that inputs must remain quiescent.
