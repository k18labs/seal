# Performance

Hash input is processed using a fixed 65,536-byte buffer. The Windows x86-64 release executable measured 1,028,096 bytes using Rust 1.96.0, `ctutils` 0.4.8, and the release profile in `Cargo.toml`; it was built on a Windows ARM64 host using x64 tools. Two clean builds on that host produced identical SHA-256 `0c8ac5cb0bad03339fe08e26995e136622104aa0b9153ce9d57923be07b2fb4c`; the exact evidence is in `docs/evidence/reproducibility-windows-x64-local.json`. This checks one target on one host and is not a cross-host reproducibility result. The manual benchmark workflow compares warm-cache SHA-256 and BLAKE3 against `sha256sum` and `b3sum`, and measures startup, file and manifest signing/verification, manifest creation for many-small-file and large-file trees, peak child RSS, and release binary size. Timing runs include process startup; RSS is a single-run high-water measurement. No complete operation benchmark run has been recorded yet. Record OS, CPU, compiler, build profile, input size, warm-up, repetitions, and baseline tool before publishing comparisons.
